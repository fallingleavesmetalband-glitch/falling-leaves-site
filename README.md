# falling-leaves.com

Official website of Falling Leaves. Static HTML/CSS, no build step. Deployed on Vercel.

- Pages: `index.html`, `music.html`, `live.html`, `press.html`, `404.html`
- Styles: `assets/style.css` · Images: `assets/img/`
- Press downloads (full-size photos, logos, cover, press-kit ZIP, tech rider): `downloads/`
- `vercel.json`: clean URLs, caching, and redirects from the old WordPress addresses
